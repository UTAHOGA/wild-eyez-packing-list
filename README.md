# Wild Eyez Packing List

This is a standalone Wild Eyez client packing and preparation guide page.

## What it includes

- `index.html` - branded guide page with optional narration and a continuous page reader
- `WILD EYEZ PACKING AND PREPARATION GUIDE.pdf` - the complete guide for download
- `assets/` - guide page images, branding, backgrounds, and audio

The narration is a companion to the online reader. Visitors scroll through the guide manually while listening, or open the full PDF in a separate tab.

## How to host

The easiest option is GitHub Pages:

1. Create a GitHub repository with this folder's contents.
2. Turn on GitHub Pages for the repository.
3. Use the published Pages URL inside Wix as an iframe source.

## Wix use

Embed the hosted `index.html` page in a real page such as `/packing-list`. If Wix caches the old source, delete the embed element and add a fresh one after changing the slug.
